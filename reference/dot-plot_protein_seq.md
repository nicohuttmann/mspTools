## Usage

``` r
.plot_protein_seq(
  protein_range = c(1, 100),
  protein_width = 0.6,
  add.length = 0,
  x_lab = "protein",
  y_lab = "",
  color = "#b0b0b0",
  alpha = 0.5,
  base_size = 16
)
```

## Arguments

- protein_range:

  residue range to show, as c(start, end)

- protein_width:

  height of the protein bar

- add.length:

  padding added to each end of the sequence axis

- x_lab:

  x axis label

- y_lab:

  y axis label

- color:

  column mapped to colour

- alpha:

  column mapped to transparency

- base_size:

  base font size of the theme
