## Usage

``` r
cheatmap(matrix, draw = T, show_clusters = NULL, add_cluster_n = T, ...)
```

## Arguments

- matrix:

  numeric matrix to draw

- draw:

  draw the heatmap, or return the object unrendered

- show_clusters:

  annotate the cluster each row belongs to

- add_cluster_n:

  add the number of rows per cluster to the annotation

- ...:

  additional arguments for ComplexHeatmap::Heatmap()
