## Usage

``` r
.set_PCA_labs(p, PCx, PCy, sdev, digits = 1)
```

## Arguments

- p:

  a ggplot object to add to

- PCx:

  principal component shown on the x axis

- PCy:

  principal component shown on the y axis

- sdev:

  vector of standard deviations from the PCA

- digits:

  number of digits shown in the axis labels
