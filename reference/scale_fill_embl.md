# \#' ggplot2 'fill' color palette based on EMBL colors from https://www.embl.org/guidelines/design/design-guidelines/colours/

\#' ggplot2 'fill' color palette based on EMBL colors from
https://www.embl.org/guidelines/design/design-guidelines/colours/

## Usage

``` r
scale_fill_embl(
  palette = c("all", "decorative", "decorative_dark", "decorative_light", "primary",
    "secondary_neutral", "interactive", "ps"),
  sub = c()
)
```

## Arguments

- palette:

  EMBL color palette

- sub:

  vector to choose and order colors
